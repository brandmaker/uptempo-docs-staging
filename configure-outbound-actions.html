Configure outbound actions for activities

Outbound actions (OBAs) allow you to integrate your business processes with third-party systems by triggering external actions from within Uptempo.

Outbound actions are associated with activity types and can be triggered for any activity that uses those types.

You can create the following types of outbound actions:

  • Open a URL

  • Send an email

  • Send selected activity data to a URL (for example, to a third-party system)

Outbound actions are typically configured for you during the implementation phase by an Uptempo specialist. If you need additional information, or want to set up additional OBAs or make changes, contact your Uptempo representative.

When configuring an outbound action, your Uptempo specialist can choose whether it applies to draft activities or only to published activities. For more information about draft activities, see Work with activity drafts (Preview).
