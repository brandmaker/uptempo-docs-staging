About activity approvals

Activity approvals let your organization require formal sign-off on an activity before it moves forward. An approval covers the whole activity, including its details, budget, Impact, and KPIs.

Activity approvals are in Preview, and are not enabled in your Uptempo instance by default. Contact your Customer Success Manager to enable this feature.

How activity approvals work

Activity approvals involve three roles:

Admin

Creates approval processes, decides which activity types need approval and who approves them, and sets how approval emails are sent.

Submitter

Submits an activity for approval and sets a deadline for the decision.

Approver

Reviews requests and approves or denies them, either on the Approvals page or from the activity's details panel on the Timeline.

A typical approval follows these steps:

  1. An admin creates an approval process that covers one or more activity types.

  2. A submitter opens an activity of a covered type, selects Submit for Approval, and sets a deadline. Uptempo creates an approval request with the status Pending review, and emails the assigned approvers.

  3. Any one of the assigned approvers approves or denies the request, on the Approvals page or from the activity's details panel on the Timeline.

  4. The request moves to Approved or Denied, and the decision is recorded in the request history.

Approval processes

An approval process defines which activity types need approval, and how approvers are assigned. Each process has:

  • A name, an optional description, and a status (active or inactive).

  • One or more activity types that it covers. One process can cover several activity types, but each activity type belongs to only one active process.

  • An approver source: a submitter-to-approver mapping, or Selected by submitter.

Only activities whose type is covered by an active process can be submitted for approval. Activities of other types don't show Submit for Approval, and don't appear on the Approvals page.

How approvers are assigned

Each approval process uses one of two approver sources:

Submitter-to-approver mapping

An admin uploads a file that maps each submitter to one or more approvers, plus one default admin. When a submitter submits an activity, Uptempo assigns all approvers on that submitter's row. The submitter can't change them.

Selected by submitter

The submitter chooses one approver when submitting. Only users who can edit the activity can be selected.

With a submitter-to-approver mapping, Uptempo routes a request to the default admin when:

  • The submitter isn't listed in the mapping file.

  • None of the submitter's mapped approvers can edit the activity.

Submission is never blocked in these cases.

Approvers are fixed when a request is submitted. Changes to a process or its submitter-to-approver mapping apply to new requests only.

Request statuses

Every request has one of the following statuses:

Pending review

The request has been submitted and is waiting for a decision.

Approved

An assigned approver approved the request. Approval is final, and the activity can't be submitted for approval again.

Denied

An assigned approver denied the request. The submitter can update the activity and resubmit the request.

Each activity has only one approval request. If the request is denied, the submitter resubmits the same request instead of creating a new one.

Any one approver decides

When a request has several assigned approvers, the first approver to approve or deny settles the request. The other approvers see that the request has been decided, and by whom.

What an approval covers

An approval covers the activity as it stands when the decision is made. Activity fields aren't locked while a request is pending, so the activity can still be edited during review.

Who can see and decide on requests

  • To see a request, you need view access to the activity. You can see requests for every activity you can view, including requests that aren't assigned to you.

  • To approve or deny a request, you must be one of its assigned approvers, or an admin.

Approval emails

Uptempo emails approvers about new approval requests. Admins choose whether approvers get an email as soon as each request is submitted, a daily or weekly digest, or both.
