View a centralized audit trail for activities

The audit trail records events that take place on activities, giving you a complete historical log of who changed what, and when.

Changes to different areas of an activity, such as Estimated Costs, connected funds, and KPIs, are recorded as separate entries.

Open the audit trail

  1. In Uptempo, go to Settings > Activity Configuration.

  2. In the Access Control section of the sidebar, click Audit Trail.

The Audit Trail page opens, displaying a table of all recorded events.

    The table displays these columns:

    Time

    The date and time the event took place.

    User

    The name of the user associated with the event.

    Activity Affected

    The name of the activity the event relates to. Click the activity name to open it.

    Event Area

    The area of the activity that the event relates to, such as Activities, Estimated Costs, or Connected Investments.

    Event Type

    The type of action that took place, such as Create, Update, or Delete.

    Change

    A short description of the change.

    Filter and search the audit trail

    To find specific events, use the search field and filters above the table. By default, the table shows events from Today.

    Filter name

    Description

    Search activity name or ID

    Only show events for a specific activity, matched by name or ID

    Date Range

    Only show events that took place within a specific date range. Choose Today, Last 7 Days, Last 30 Days, Last 60 Days, or Custom to specify your own date range.

    User

    Only show events associated with a specific user

    Event Area

    Only show events related to a specific area of an activity

    Event Type

    Only show events of a specific type, such as Create, Update, or Delete. Select Custom to show events for Outbound Actions.

    Timestamps in the audit trail are shown in your local time zone, based on your browser settings.

    View event details

    To see the full details of an event, click Show more on its row. The Event Details panel opens, showing information about the activity and the event, followed by a comparison of the New value and Old value for the change.

    What appears under New value and Old value depends on the type of event:

    • For a newly created activity, all the data entered on the Details tab during creation appears under New value, and Old value is empty. Data entered on other tabs, such as Estimated Costs, Connected funds, or KPIs, is recorded as a separate event for each area.

    • For an updated activity, a separate event is recorded for each area that was changed, such as Estimated Costs. The panel shows the New value and Old value for that area.

    • For a deleted activity, all the data most recently entered on the Details tab appears under Old value, and New value is empty. Data from other tabs is recorded as separate events under their respective areas.

    Outbound Actions and changes to an activity's connected funding sources also appear as their own events in the audit trail.
